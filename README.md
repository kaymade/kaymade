## About Me

Hi, I'm Kay — a software developer building responsive web interfaces, internal tools, and applications for real users.

My frontend work includes React, TypeScript, JavaScript, HTML, CSS, and accessibility. I also work with PostgreSQL, authentication, APIs, and third-party integrations.

I've built and maintained production software for a business, contributed to collaborative applications, reviewed pull requests, and published themes used by the Obsidian community. My background in organizational leadership and client-facing work shapes how I approach development: understand the problem, communicate clearly, and build for the people who will use the software.

I'm seeking a software development role with a focus on frontend engineering and user interfaces.

## Featured Work

### Golden Years Tech Help

A production website and authenticated staff CRM built for a senior technology-support business.

I designed and built the public interface and internal workflows for lead intake, customer records, scheduling, technician assignments, billing, payments, email, and audit history. The system combines PostgreSQL Row Level Security, server-side functions, and integrations with Google Calendar, Stripe, and Resend.

**Stack:** HTML · CSS · JavaScript · TypeScript · PostgreSQL · Supabase · Netlify

[Technical case study](https://github.com/kaymade/golden-years-case-study) · [Live website](https://www.goldenyearsth.com/) · [Portfolio details](https://kaymade.github.io/projects.html#golden-years)

Production source code is private; the public case study documents the architecture, screenshots, testing, and engineering decisions.
